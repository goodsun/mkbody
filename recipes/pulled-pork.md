# プルドポーク

## 材料

- 豚肩ロース 500g
- マキシマム 大さじ1（約10g）
- UMAMIバーベキューソース スモーキー（食べるときに1食あたり大さじ1・約18g）

## 作り方

1. 豚肩ロースにマキシマムをすり込み、耐熱袋に入れて空気を抜く
2. 低温調理する（ほぐれる柔らかさにするなら高めの温度で長時間が目安）
3. ほぐす前に100g分をスライスして取り分けるとチャーシューになる
4. 残りをフォークでほぐす。袋に残る肉汁（50〜80ml）は冷凍保存
5. 食べるときにBBQソースをかける

## 1回の仕込みで取れるもの

- プルドポーク 4食分（100g×4）
- チャーシュー 1食分（スライス100g）
- つけ汁ベース用の肉汁 50〜80ml

2kgで仕込む場合は500g×4袋に分けて同時調理する。20食分と肉汁200〜320ml（つけ汁2〜3杯分）になる。

## 栄養メモ（1食 = 肉100g+マキシマム2g+ソース18g）

276kcal / たんぱく質17.7g / 脂質19.3g / 炭水化物9.3g / 食塩相当量2.0g

- ソース抜き（チャーシューとして食べる場合）は240kcal / 食塩相当量1.3g
- 塩分2.0gの主因はマキシマム（食塩相当量61.1%）。減塩したい日はソースを半量に
- ビタミンB1が豊富。B12豊富なプルドビーフと交互に作ると補完になる
