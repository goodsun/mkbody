# フィナンシェ（研究中）

アーモンドプードルと焦がしバターの焼き菓子。基本は本来の形のアーモンド。アレンジとしてパルメザン版を持つ。
卵白だけを使うので、[カルボナーラ](sous-vide-carbonara.md) で余る卵白の使い道になる。日持ちがするので、コースでは手土産にする。

名前の由来には、パリの金融街で金の延べ棒の形に焼かれたという説がある。

## 基本：フィナンシェ（フィナンシェ型 約10個分）

### 材料

| 材料 | 分量 |
|------|------|
| 卵白 | 100g |
| グラニュー糖 | 80〜100g |
| はちみつ | 10g |
| アーモンドプードル | 70g |
| 薄力粉 | 35g |
| 無塩バター | 90g |
| 塩 | ひとつまみ |
| 仕上げ用スライスアーモンド | 適量 |

### 下準備

- 型にやわらかいバターを薄く塗り、強力粉をはたいて冷蔵庫で冷やしておく
- アーモンドプードル、薄力粉、塩を合わせてふるっておく

### 手順

1. **焦がしバターを作る**：小鍋でバターを中火にかけ、泡が細かくなって薄い茶色になるまで加熱する。ヘーゼルナッツのような香りがしたら鍋底を水につけて止める。茶こしでこして、50〜60℃くらいに保つ
2. **卵白をほぐす**：ボウルに卵白を入れ、泡立て器でコシを切る程度にほぐす。泡立てない
3. グラニュー糖とはちみつを加え、すり混ぜる
4. 合わせた粉類を加え、なめらかになるまで混ぜる
5. 焦がしバターを3回に分けて加え、そのたびにしっかり混ぜてつやのある生地にする
6. ラップをして冷蔵庫で1時間以上休ませる。一晩おくとさらに味がなじむ
7. 型の8分目まで生地を入れ、上にスライスアーモンドを散らす
8. 200℃に予熱したオーブンで12〜14分焼く。縁がこんがりして、中央を押して弾力があれば焼き上がり
9. すぐに型から外し、網の上で冷ます

## バリエーション：パルメザンのフィナンシェ

基本からの差分で書く。ワインのおつまみにもなる、甘さ控えめの塩味寄りの一品。

| | 基本 | パルメザン版 |
|------|------|------|
| グラニュー糖 | 80〜100g | 60g |
| アーモンドプードル | 70g | 40g |
| パルメザン（細かくすりおろす） | なし | 30g（粉類と一緒にふるう） |
| 焦がしバター | 薄い茶色で止め、アーモンドの香りを活かす | 普通より少し濃いめまで攻め、チーズに負けない香りにする。黒くなる手前が目安 |
| 仕上げ | スライスアーモンド | 仕上げ用パルメザン適量、好みで黒こしょう |

### パルメザン版のポイント

- 砂糖はチーズの塩気に合わせて控えめにしている
- パルメザンはブロックから。粉チーズでも作れるが、香りの強さがまるで違う
- 上に散らすチーズが大事。焼くとカリッとした香ばしい層になり、食感のアクセントになる

## 科学解説

### 1. 焦がしバター

- バターの水分が飛ぶと温度が100℃を超えて上がり、乳タンパクと乳糖がメイラード反応を起こす。ヘーゼルナッツのような香りの正体はこれ
- 泡が細かくなるのは、水分が抜けた合図
- 鍋底を水につけるのは、余熱で焦げすぎるのを止めるため
- 焦がす濃さが香りの強さを決める。合わせる素材の強さで止める位置を変える

### 2. 焦がしバターを50〜60℃に保つ

熱すぎると卵白が固まり、冷めすぎると生地に混ざらない。

### 3. 卵白を泡立てない

泡で膨らませないので、詰まったしっとりした食感になる。泡立てると膨らみすぎて、フィナンシェらしさがなくなる。

### 4. はちみつ

はちみつの果糖は湿気を抱えるので、焼いた後もしっとりが続く。焼き色もつきやすくなる。日持ちのよさの理由の一つ。

### 5. 生地を休ませる

粉に水分が行き渡り、生地の中の泡も抜ける。焼き上がりのきめがそろう。

### 6. 200℃の高温で短く焼く

表面と縁を一気に焼き固めて、香ばしい外側としっとりした内側の差を作る。

### 7. すぐに型から外す

型の中に蒸気がこもると、表面が湿ってしまう。

## コースでの使い方

[コンフィのコース](confit-course.md) では、基本のフィナンシェを帰り際の手土産にする。

- 濃い皿が続いたコースの最後に添えるには重い。コース中は軽い [ラング・ド・シャ](langue-de-chat.md)、帰り際にフィナンシェと分ける
- はちみつとアーモンドで数日しっとりが続くので、手土産に向く
- メニューカードの最後でレシピ集に案内するのと同じく、物語が家に帰ってからも続く

### 卵白の配分

卵白は1個あたり約30〜35g。

| コースの人数 | 余る卵白 | 使い道 |
|------|------|------|
| 2人 | 2個（約65g） | ラング・ド・シャ1回分（50g）。フィナンシェは卵白を別に足す |
| 4人 | 4個（約130g） | ラング・ド・シャ1回分（50g）と、フィナンシェ半量（50g、約5個） |

## 保存

- 密閉容器で常温。数日はしっとりが続く
- 長く保存するなら1個ずつ包んで冷凍。食べる前に常温に戻す

## 注意点

- ナッツを含む。アレルギーのある人に渡すときは確認する

## 検証予定

- 基本の砂糖（80gと100g）で甘さとしっとり感を比べる
- 焦がしバターの濃さ（薄い茶色と濃いめ）で香りを比べる
- 基本とパルメザン版を同じ日に焼き比べる
- 何日までしっとりが保てるか
