# インテルメッツォの飲み物：クラフトコーラとレモネード（研究中）

[コンフィのコース](confit-course.md) で、パルミジャーナとカルボナーラの間に出す一杯の候補。各25〜30mlのごく少量。
炭酸が苦手な人にはレモネードを出す。同じ役割の一杯を、ゲストに合わせて違う形で出す。
採用は確定していない。検証で勝ったらコースに正式に組み込む。

## 役割

- **コースの弱点を埋める**：パルミジャーナ、カルボナーラ、コンフィと濃い皿が三連続になる。コンフィの前にはグラニータがあるが、パルミジャーナとカルボナーラの間には区切りがなかった
- **段取りを助ける**：ゲストが飲んでいる間にパスタを仕上げられる。グラニータがコンフィの皮を焼く時間を作るのと同じ
- **物語**：アミューズのプルドポークで出たアメリカの遊び心が、クラフトコーラとして途中で戻ってくる。ノンアルコールで飲み物まで設計の対象にする

**評価の基準**：飲み物単体でどちらがおいしいかではなく、飲んだ後のカルボナーラがどちらでおいしくなるか。この基準は変えない。

## クラフトコーラ

普通のクラフトコーラを甘さ控えめにするだけでは失敗する。コーラの魅力であるスパイスの複雑さが、カルボナーラの繊細な卵黄や小麦の香りを邪魔するから。目的はコーラとしての完成度ではなく、パルミジャーナの余韻を整えてカルボナーラをおいしく感じさせること。

### スパイスの選び方

| 素材 | 採用方針 | 理由 |
|------|------|------|
| オレンジピール | ◎ | トマトの余韻から自然に移行する |
| カルダモン | ○ | 清涼感と華やかな香り。黒胡椒と同じテルペン類の香りで、カルボナーラへの橋渡しになりうる |
| ショウガ | ○ | 控えめなら後味を引き締める |
| レモン果汁 | ○ | 少量で酸味の輪郭を作る（柑橘の重なりに注意） |
| シナモン | △ | 甘い印象が強く、卵黄を邪魔する可能性 |
| クローブ | △ | 香りの主成分オイゲノールが強く残りやすい |
| カラメル | △ | 色づけには使えるが、苦味や焦がし香が増える |

最初の試作では、シナモンとクローブは抜くか痕跡程度にする。

### 試作配合（約5杯分、各25ml）

| 材料 | 分量 |
|------|------|
| 炭酸水 | 110ml |
| オレンジピールのシロップ | 10ml |
| カルダモンとショウガの抽出液 | 3ml |
| レモン果汁 | 1〜2ml |
| 砂糖 | 2〜3g（シロップ作りに使う） |

糖度は通常のコーラよりずっと低くする。甘味ではなく、炭酸と柑橘とスパイスの香りを楽しませる設計。最終的な甘味、酸味、香りは試飲で調整する。

### 香りの抽出

- **柑橘の皮はオレオサッカラムで**：オレンジピールの香りの主成分リモネンは水にほとんど溶けない。皮に砂糖をまぶして置くと、浸透圧で皮の油が砂糖に引き出され、香りの濃いシロップになる。カクテルで使われる方法。どうせ砂糖を少し使うので、その砂糖で皮の香りを抜く
- **カルダモンはさやを割って熱いお湯で**：香りの多くは油に溶けやすい成分で、水には出にくい。さやを割って表面積を増やし、熱いお湯で抽出して冷やす

## レモネード

炭酸が苦手な人のための一杯。

### ハーブの候補

| ハーブ | 評価 | 理由 |
|------|------|------|
| レモンバーベナ | 第一候補 | 香りの主成分シトラール（ゲラニアールとネラール）はレモンの香りの中心と同じ。果汁を増やさずにレモンの香りに厚みを出せる |
| タイム | 次点 | 木質的で落ち着いた香り。パルミジャーナの余韻と接続しやすい。強すぎると卵黄を覆う |
| スイートバジル | 次点 | トマトのパルミジャーナから自然につながる。ただしパルミジャーナにもバジルを使うので香りが重複する |
| ミント | 慎重に | メントールは舌の冷感センサーを直接刺激し、感覚が長く残る。次のカルボナーラの温かさを鈍らせる可能性。使うならスペアミントを少量 |

### 試作配合：レモンバーベナ（仕込み約150ml、各25〜30mlで約5杯分）

| 材料 | 分量 |
|------|------|
| 水 | 120ml |
| レモン果汁 | 15ml |
| 砂糖 | 7g |
| レモンの皮 | 少量 |
| 生のレモンバーベナ | 2〜3枚 |

1. 水の一部を60〜70℃に温め、レモンバーベナとレモンの皮を入れて蓋をし、3〜5分抽出する
2. 濾して砂糖を溶かす
3. 冷やしてから、果汁と残りの水を加える

- **60〜70℃で蓋をする理由**：沸騰したお湯では香りが飛び、葉の苦味も出やすい。低めの温度で蓋をすれば、揮発しやすい香りを閉じ込められる
- **量は1杯25〜30ml**：150mlを一人で飲むと、カルボナーラの前にお腹がふくれる。150mlは5杯分の仕込み量
- 抽出温度と時間、ハーブの量は試作条件。葉の大きさや鮮度で調整する

### 香りの橋渡しの仮説：レモン、バジル、黒胡椒

パルミジャーナのトマトとバジルの組み合わせを受け継ぎ、黒胡椒をほんの少し加えて次のカルボナーラへつなぐ。ただし香りを重ねるほど、口直しなのに余韻が長すぎるリスクがある。まずレモンバーベナ単独で試し、次にバジル版と比べる。

## 一つの仕込みで二つの飲み物（別案）

コーラとレモネードを別々に作らず、共通の香りのベースから作る方法もある。

| | 共通のベース | 仕上げ |
|------|------|------|
| クラフトコーラ | オレンジピールのシロップ＋カルダモンとショウガの抽出液 | 炭酸水で割る |
| レモネード | 同じベース | 水とレモン果汁で割る |

仕込みが一回で済み、二人が同じ香りを共有できる。ただしレモンバーベナ案とは別物になるので、どちらの香りを採るかは試して決める。

## コースへの影響

- **柑橘が重なる**：レモネードやコーラのレモンを採用すると、カルパッチョのグレープフルーツ、グラニータのレモンと柑橘が続く。特に口直しが二回ともレモンになるのは避けたい。採用する場合、グラニータは柑橘以外にする（候補は青りんご。りんご酸の鋭い酸味で、柑橘とは別の系統）
- **幕間が二回になる**：コースが序、第一幕、幕間1、第二幕、幕間2、第三幕の構成になる。少量なので満腹への影響はほぼないが、区切りが多いとテンポが細切れに感じる可能性がある
- **段取り**：抽出液とシロップは前日に仕込める。当日は割って注ぐだけ。パルミジャーナを下げてからパスタを茹でている間に出す

## 安全と保存

- 抽出液とシロップは冷蔵で保存し、数日以内に使う
- 炭酸水で割るのは出す直前。炭酸は時間とともに抜ける

## 検証予定

1. **炭酸の三者比較**：甘さを抑えたクラフトコーラ、柑橘の微炭酸水、プレーンの炭酸水を同じ25mlで比べる。その後に同じカルボナーラを食べて、卵黄の風味、黒胡椒の香り、前の皿の余韻を評価する。効果が炭酸から来ているのか、香りから来ているのかを切り分ける
2. **レモネードの比較**：レモンバーベナ版とバジル版。評価はカルボナーラを食べた後で
3. **仕込みの比較**：共通ベース案と、個別に作る案
4. **テンポの確認**：幕間が二回あるコースの流れが細切れに感じないか
5. 炭酸による口直しの効果は、対象の食品や評価する感覚によって変わり、一律に優れているわけではないとされる（外部レビューより）。だから比較の対照を必ず置く
