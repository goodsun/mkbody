# ノンアルコールドリンク：クラフトコーラとハーブレモネード（研究中）

ノンアルコールドリンクの二本柱。単独で注文したくなるほど完成度の高い一杯を目指し、コースではそれを少量で出す。
コースのために作った口直しをドリンクにするのではない。単独で成立するドリンクを、コースに組み込む。この順番のほうが店としてずっと強い。
炭酸が苦手な人にはレモネードを出す。同じ役割の一杯を、ゲストに合わせて違う形で出す。

## 設計思想

料理は料理で最高を目指す。ドリンクもドリンクで最高を目指す。そのうえで組み合わせを最適化する。
単独で成立するもの同士を組み合わせて、単独以上の体験にする。レシピ集の各料理が単独のレシピとして成立し、[コンフィのコース](confit-course.md) がそれを組み合わせているのと同じ構造。

## 二つの提供形態

| | 通常メニュー版 | コース版 |
|------|------|------|
| 量 | 200〜250ml | 20〜30ml |
| 位置 | 単独の一杯 | パルミジャーナとカルボナーラの間 |
| 濃度 | 基本の配合 | 必要なら皮の香りを少し強める |
| 仕込み | 共通 | 共通 |

レシピは共通化しながら、提供体験を変える。コースと通常メニューで別々のドリンクを開発する必要はない。

**コース版を少し濃くする理由**：少量だと、口に含んでいる時間も、飲み込んだ後に鼻に抜ける香りの時間も短い。同じ濃度だと印象が薄くなる。ただし二つが必ずしも同じ配合になる必要はない。基本のドリンクのおいしさを優先し、コースへの組み込み方は後から考える。

## 評価基準（二段階）

| 段階 | 基準 | 対象 |
|------|------|------|
| 第一 | 単独で一杯飲みきって、もう一度注文したくなるか | 通常メニュー版 |
| 第二 | コースの中で次の料理を邪魔せず、おいしくするか。飲んだ後のカルボナーラがおいしくなるか | コース版 |

作り手のこだわりが強すぎると、香りの複雑さばかりが増えて飲みやすさを失う。特にクラフトコーラは「複雑で面白いけど、一杯は飲みきれない」ものになりやすい。試作では「最後まで飲みきれたか」を必ず記録する。

## クラフトコーラ

普通のクラフトコーラを甘さ控えめにするだけでは、コースで失敗する。コーラの魅力であるスパイスの複雑さが、カルボナーラの繊細な卵黄や小麦の香りを邪魔するから。

### スパイスの選び方

| 素材 | 採用方針 | 理由 |
|------|------|------|
| オレンジピール | ◎ | トマトの余韻から自然に移行する |
| カルダモン | ○ | 清涼感と華やかな香り。黒胡椒と同じテルペン類の香りで、カルボナーラへの橋渡しになりうる |
| ショウガ | ○ | 控えめなら後味を引き締める |
| レモン果汁 | ○ | 少量で酸味の輪郭を作る（柑橘の重なりに注意） |
| シナモン | △ | 甘い印象が強く、卵黄を邪魔する可能性 |
| クローブ | △ | 香りの主成分オイゲノールが強く残りやすい |
| カラメル | △ | 色づけには使えるが、苦味や焦がし香が増える |

最初の試作では、シナモンとクローブは抜くか痕跡程度にする。通常メニュー版で物足りなければ、痕跡程度から足して「飲みきれるか」で上限を決める。

### 試作配合（コース版、約5杯分、各25ml）

| 材料 | 分量 |
|------|------|
| 炭酸水 | 110ml |
| オレンジピールのシロップ | 10ml |
| カルダモンとショウガの抽出液 | 3ml |
| レモン果汁 | 1〜2ml |
| 砂糖 | 2〜3g（シロップ作りに使う） |

糖度は通常のコーラよりずっと低くする。通常メニュー版は、同じシロップと抽出液を使い、単独で飲んで物足りなくない甘さまで試飲で調整する。

### 香りの抽出

- **柑橘の皮はオレオサッカラムで**：オレンジピールの香りの主成分リモネンは水にほとんど溶けない。皮に砂糖をまぶして置くと、浸透圧で皮の油が砂糖に引き出され、香りの濃いシロップになる。カクテルで使われる方法
- **カルダモンはさやを割って熱いお湯で**：香りの多くは油に溶けやすい成分で、水には出にくい。さやを割って表面積を増やし、熱いお湯で抽出して冷やす

## ハーブレモネード

レモンの鮮烈な香りから、穏やかなハーブの余韻へ。甘さを抑え、果実の酸味と植物の香りを楽しむ一杯。

### 目指す仕上がり

| 要素 | 目指す仕上がり |
|------|------|
| 甘味 | 控えめだが、単独で飲んでも物足りなくない |
| 酸味 | 明瞭だが、飲み疲れない |
| 香り | レモン果皮とハーブの立体的な香り |
| 苦味 | 果皮由来の心地よい微かな苦味 |
| 余韻 | ハーブが穏やかに残り、もう一口欲しくなる |

### ハーブの候補

| ハーブ | 評価 | 理由 |
|------|------|------|
| レモンバーベナ | 主役 | 香りの主成分シトラール（ゲラニアールとネラール）はレモンの香りの中心と同じ。果汁を増やさずにレモンの香りに厚みを出せる |
| ローズマリー | 奥行き担当（ごく微量） | レモンバーベナが華やかさ、ローズマリーが奥行き。香りの主成分シネオールやカンファーは強く残るので、微量から試す |
| タイム | 次点 | 木質的で落ち着いた香り。強すぎると卵黄を覆う |
| スイートバジル | 次点 | トマトのパルミジャーナから自然につながる。ただしパルミジャーナにもバジルを使うので香りが重複する |
| ミント | 慎重に | メントールは舌の冷感センサーを直接刺激し、感覚が長く残る。次のカルボナーラの温かさを鈍らせる可能性 |

### 試作配合：レモンバーベナとローズマリー（仕込み約150ml）

| 材料 | 分量 |
|------|------|
| 水 | 120ml |
| レモン果汁（当日搾る） | 15ml |
| 砂糖 | 7g |
| レモンの皮 | 少量 |
| 生のレモンバーベナ | 2〜3枚 |
| ローズマリー | ごく微量（葉を数枚） |

1. 水の一部を60〜70℃に温め、レモンバーベナとレモンの皮を入れて蓋をし、3〜5分抽出する
2. ローズマリーは抽出の最後の1分だけ入れる。時間で香りの強さを調整する
3. 濾して砂糖を溶かす
4. 冷やしてから、果汁と残りの水を加える

150mlで、通常メニュー版なら1杯弱、コース版なら5杯分。抽出温度と時間、ハーブの量は試作条件。

### 科学解説

- **60〜70℃で蓋をする**：沸騰したお湯では香りが飛び、葉の苦味も出やすい。低めの温度で蓋をすれば、揮発しやすい香りを閉じ込められる
- **果汁はその日に搾る**：レモン果汁には、搾った直後は苦くない成分が含まれている。それが酸性の果汁の中で数時間かけて苦味成分（リモニン）に変わる。柑橘の「遅れて出る苦味」として知られる現象。作り置きの果汁は、意図しない苦味を持つ
- **心地よい苦味は皮で設計する**：果汁の遅れて出る苦味に頼らず、皮の量で狙った苦味を作る。白いわたの部分は苦味が強いので、使う量で調整する

### 香りの橋渡しの仮説：レモン、バジル、黒胡椒

パルミジャーナのトマトとバジルを受け継ぎ、黒胡椒をほんの少し加えて次のカルボナーラへつなぐ。ただし香りを重ねるほど、口直しなのに余韻が長すぎるリスクがある。コース専用の変化形として、基本のレモネードが固まってから試す。

## 一つの仕込みで二つの飲み物（別案）

コーラとレモネードを共通の香りのベースから作る方法もある。

| | 共通のベース | 仕上げ |
|------|------|------|
| クラフトコーラ | オレンジピールのシロップ＋カルダモンとショウガの抽出液 | 炭酸水で割る |
| レモネード | 同じベース | 水とレモン果汁で割る |

仕込みは一回で済む。ただし二本柱として単独の完成度を目指すなら、それぞれの香りを独立に詰めたほうがよい可能性が高い。どちらを採るかは試して決める。

## コースへの影響

- **柑橘が重なる**：カルパッチョのグレープフルーツ、グラニータのレモンと柑橘が続く。特に口直しが二回ともレモンになるのは避けたい。レモネードを採用する場合、グラニータは柑橘以外にする（候補は青りんご）
- **幕間が二回になる**：少量なので満腹への影響はほぼないが、区切りが多いとテンポが細切れに感じる可能性がある
- **段取り**：シロップと抽出液は前日に仕込める。レモン果汁だけは当日搾る。炭酸水で割るのは出す直前

## 安全と保存

- シロップと抽出液は冷蔵で保存し、数日以内に使う
- 炭酸水で割るのは出す直前。炭酸は時間とともに抜ける

## 検証予定

1. **単独での評価**：通常メニュー版を一杯飲みきれるか。もう一度注文したくなるか
2. **炭酸の三者比較**：クラフトコーラ（コース版）、柑橘の微炭酸水、プレーンの炭酸水を同じ25mlで比べ、その後に同じカルボナーラを食べて評価する。効果が炭酸から来ているのか、香りから来ているのかを切り分ける
3. **レモネードの比較**：レモンバーベナ単独と、ローズマリーを加えた版。次にバジル版
4. **濃度の比較**：コース版を通常メニュー版と同じ濃度にした場合と、皮の香りを強めた場合
5. **仕込みの比較**：共通ベース案と、個別に作る案
6. **テンポの確認**：幕間が二回あるコースの流れが細切れに感じないか
7. 炭酸による口直しの効果は、対象の食品や評価する感覚によって変わり、一律に優れているわけではないとされる（外部レビューより）。だから比較の対照を必ず置く
