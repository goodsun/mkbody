# 牛すね肉のビーフシチュー（研究中）

鶏はチキンカレー、豚はプルドポーク、牛はビーフシチュー。動物ごとに、部位の性質が一番活きる料理を割り当てる。
牛すねはコラーゲンが非常に多く、煮込むとほろほろになる。真空パックで二段階の低温調理をし、食べるときにオーブンで焼きの香りを足す。
土台は炊飯器（JBH-G181）の説明書のビーフシチュー（調理メニュー120分）。温度と時間は未検証。

## 経緯

[プルドビーフ](pulled-beef.md) を牛肩ロースで作ったら、ジャーキーのようになった。肩ロースは脂とコラーゲンが少なく、長時間加熱で乾いた筋線維を補うものがなかった。そこで牛はほぐす料理をやめ、コラーゲンの多いすね肉で煮込みにする。

| 動物 | 料理 | 部位 | 活きている性質 |
|------|------|------|------|
| 鶏 | [チキンカレー](chicken-curry.md) | 手羽元 | 骨とコラーゲンから出るゼラチンのとろみ |
| 豚 | [プルドポーク](pulled-pork.md) | 肩ロース | 脂と結合組織で、ほぐしてもしっとり |
| 牛 | ビーフシチュー | すね | コラーゲンが非常に多く、煮込むとほろほろ |

## 材料（4人分・暫定）

### 肉とソース（袋に入れる）

| 材料 | 分量 |
|------|------|
| 牛すね肉（大きめの角切り） | 600g（加熱で3割ほど縮む） |
| 塩、こしょう | 少々 |
| 薄力粉 | 少々（任意） |
| サラダ油 | 大さじ1 |
| 玉ねぎ（薄切り） | 1/2個 |
| 赤ワイン | 200ml（半量まで煮詰める） |
| デミグラスソース | 200g |
| ブイヨン | 100ml |
| ローリエ | 1枚 |
| クローブ | 1個（任意） |
| 砂糖 | 少々 |

ブイヨンは説明書の300mlから減らしている。密閉で蒸発しないので、肉から出る汁と合わせて濃度が決まる。

### 付け合わせ野菜（別に用意する）

| 材料 | 分量 | 下ごしらえ |
|------|------|------|
| じゃがいも | 200g | 4等分して沸騰した湯から下茹で |
| にんじん | 100g | 乱切りにして沸騰した湯から下茹で |
| マッシュルーム | 8個 | バターで焼き色をつける |
| ブロッコリー | 60g | 小房に分け、食べる直前に塩茹で |

## 手順

### 仕込み（加熱から冷凍まで）

1. **焼く**：すね肉に塩、こしょうをして、好みで薄力粉を薄くまぶす。フライパンに油を熱し、全面にしっかり焼き色をつけて取り出す
2. **玉ねぎを炒める**：同じフライパンで玉ねぎをしんなりするまで炒める
3. **赤ワインを煮詰める**：赤ワインを加え、鍋底の焼き付きをこそげながら半量まで煮詰める
4. **ソースを作る**：デミグラスソース、ブイヨン、砂糖を加えて混ぜ、冷ます
5. **ソースを固める**：ソースを冷蔵で冷やしてとろみをつけるか、1人前ずつ凍らせてブロックにする
6. **1人前ずつ真空パック**：肉とソース（またはソースのブロック）、ローリエとクローブを分けて入れ、真空パックする
7. **第一段：90℃で2時間**：低温調理器で加熱する
8. **第二段：75℃で10時間**：温度を下げて続ける
9. **急冷**：袋ごと氷水で一気に冷やす
10. **保存**：冷蔵で寝かせて数日以内に食べるか、そのまま冷凍する

### 食べる日

1. **湯煎で温める**：袋ごと湯煎する。冷凍なら解凍を兼ねて時間を長めにとる
2. **耐熱皿に盛る**：シチューを耐熱皿に移し、下茹でしたじゃがいもとにんじん、焼いたマッシュルームを添える
3. **オーブンで焼く**：200℃で10〜15分。ソースの表面と縁がふつふつして色づくまで
4. **仕上げ**：塩茹でしたブロッコリーを添える

## 科学解説

### 1. 二段階加熱

| 段階 | 温度 | 時間 | 狙い |
|------|------|------|------|
| 第一段 | 90℃ | 2時間 | 牛すねの熱に強いコラーゲンを一気にほどく |
| 第二段 | 75℃ | 10時間 | ほどけ始めたコラーゲンをゆっくりゼラチンに変え続ける。肉を締めすぎずに味をしみ込ませる |

- 牛すねのコラーゲンは、熱に強い結びつきが多い。鶏の手羽元のように72〜75℃だけでは溶けきらない可能性があるので、先に90℃でほどく
- 炊飯器版の「調理メニュー120分（沸騰近くから約93℃、約88℃と下がる）から保温」と同じ構造を、温度を指定して再現している
- 75℃10時間で十分に柔らかくなるかは検証する

### 2. 焼き色は最初と最後に

- 袋の中は75〜90℃なので、メイラード反応は起きない
- 最初に肉の表面を焼いて香ばしさを作る。最後にオーブンでソースの表面と縁を焼き、もう一度焼きの香りを足す
- 低温で食感を作り、高温で香りを作る。[コンボパック](pulled-combo-pack.md) のコンフィや [パルミジャーナ](eggplant-parmigiana.md) と同じ分担

### 3. 赤ワインは先に煮詰める

袋の中は密閉なので、アルコールも酸の角も飛ばない。[チキンカレー](chicken-curry.md) で「密閉すると蒸発しない」と書いたのと同じ理屈。袋に入れる前に半量まで煮詰めて、アルコールと酸の角を飛ばしておく。

### 4. 液体は固めてから真空にかける

液体が多いと真空パック機がソースを吸い込む。冷やしてとろみをつけるか、凍らせたブロックにしてから入れる。[プルドポークのペンネ](pulled-pork-penne.md) で話した冷凍ブロックの考え方がそのまま使える。

### 5. 付け合わせ野菜は別にする

- 肉と一緒に12時間入れると、煮崩れたり風味が抜けたりする
- じゃがいもとにんじんは、沸騰した湯から下茹でする。60〜70℃台を長く通すと細胞壁を硬くする酵素が働き、柔らかくなりにくい
- オーブンの10〜15分では生の根菜に火が通らないので、下茹でしてから添える
- ブロッコリーの緑はクロロフィル。加熱が長いとくすむので、直前に茹でて最後に添える。[枝豆のポタージュ](edamame-potage.md) と同じ理屈

### 6. 1人前ずつ真空パックする

加熱前に1人前ずつ分けておけば、仕上がった後に袋を開け直さずにそのまま冷凍できる。空気に触れないので冷凍焼けしにくい。

## 安全メモ

- 真空パックは酸素のない環境。90℃と75℃で一般的な菌は死ぬが、ボツリヌス菌やウェルシュ菌の芽胞は生き残る
- 加熱後は袋ごと氷水で急冷し、冷蔵なら数日以内に食べきる。それ以上は冷凍する
- 食べるときは中心までしっかり温める
- 袋は90℃で2時間に耐えるものを使う。低温調理器が90℃に対応しているかも確認する。水の蒸発が速いので、蓋かラップで覆う
- 袋が浮くと加熱がむらになるので重しを乗せる

## 検証予定

- 90℃2時間と75℃10時間で、すね肉がほろほろになるか
- 第二段の時間を変えて比べる（6時間、10時間）
- ブイヨンの量（密閉で蒸発しないので、ソースの濃度を確かめる）
- 冷凍から湯煎で温める時間
- オーブンの温度と時間（ソースの焼き色）
- 出来上がり重量を測り、1食分の栄養値を出してCSVに追加する
