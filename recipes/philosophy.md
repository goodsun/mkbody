# 設計思想：物理で料理

料理を「煮込む」「焼く」といった作業ではなく、温度と時間の設計として扱う。
起きる現象そのものは変えられない。でも、どのタイミングで起こすかは選べる。そうすると、欠点とされていた現象が工程に変わる。

## レシピをまたいで使っている原理

| 原理 | 中身 | 使っているレシピ |
|------|------|------|
| コラーゲンは70℃台の長時間でゼラチンになる | 沸騰させずに時間をかけて柔らかくする | [チキンカレー](chicken-curry.md)、[コンボパック](pulled-combo-pack.md)、[タコのカルパッチョ](sous-vide-octopus-carpaccio.md) |
| 卵黄は65℃でとろみ、70℃で固まる | 5℃の幅を低温調理器で狙う | [カルボナーラ](sous-vide-carbonara.md) |
| 野菜の軟化は85℃前後から | 野菜には肉より高い温度を割り当てる | [パルミジャーナ](eggplant-parmigiana.md) |
| 沸かさなければ濁らない | 対流を起こさず、脂とタンパク質を分散させない | [コンフィのコース](confit-course.md)のブロード |
| メイラード反応は水があると進まない | 先に水を飛ばしてから焼き色をつける | [チキンカレー](chicken-curry.md)、[BBQソース](bbq-sauce.md)、[パルミジャーナ](eggplant-parmigiana.md)、[コンボパック](pulled-combo-pack.md)のコンフィ |
| 香りは揮発する、または油に溶ける | 香りは最後に入れる。スパイスは油で開く | [チキンカレー](chicken-curry.md)、[BBQソース](bbq-sauce.md)、[パルミジャーナ](eggplant-parmigiana.md)、[カルボナーラ](sous-vide-carbonara.md) |
| クロロフィルは熱と酸で退色する | 加熱は短く、蓋をせず、すぐ急冷する | [枝豆のポタージュ](edamame-potage.md) |
| 密閉すると蒸発しない | 濃度は煮詰めではなく入口の水量で決める | [チキンカレー](chicken-curry.md)、[コンボパック](pulled-combo-pack.md) |
| 旨味は掛け算で、しかも頭打ちになる | グルタミン酸とイノシン酸を組み合わせ、足しすぎない | [BBQソース](bbq-sauce.md)、[パルミジャーナ](eggplant-parmigiana.md)、[真鯛のカルパッチョ](kombujime-tai-carpaccio.md) |
| 酸はタンパク質を変性させる | 生の魚には直前にかける。加熱済みなら先にかけてなじませる | [真鯛のカルパッチョ](kombujime-tai-carpaccio.md)、[タコのカルパッチョ](sous-vide-octopus-carpaccio.md) |
| 芽胞は加熱を生き残る | 加熱のあとは必ず急冷し、危険な温度帯を一気に通過させる | 低温調理するすべてのレシピ |
| 冷蔵で寝かせると味が分配される | 急冷のあと冷蔵で休ませる | [チキンカレー](chicken-curry.md)、[コンボパック](pulled-combo-pack.md)、[タコのカルパッチョ](sous-vide-octopus-carpaccio.md) |
| 氷の結晶は組織を壊す | 欠点として避けるか、下処理として使うかを選ぶ | [パルミジャーナ](eggplant-parmigiana.md)、[タコのカルパッチョ](sous-vide-octopus-carpaccio.md) |
| 氷の結晶の大きさが食感を決める | 粗くしたいなら削り、細かくしたいなら混ぜながら速く凍らせる | [ジェラート](gelato-allo-yogurt.md)、[コンフィのコース](confit-course.md)のグラニータ |

## 単独で成立するもの同士を組み合わせる

料理は料理で最高を目指す。ドリンクもドリンクで最高を目指す。そのうえで組み合わせを最適化する。

- 各レシピは単独で成立させる。[コンフィのコース](confit-course.md) は、それらを組み合わせる設計図にすぎない
- コースのために専用品を作るのではなく、単独で完成度の高いものを、コースでは量や濃度を変えて出す（[ノンアルコールドリンク](intermezzo-drinks.md)）
- 評価は二段階。単独でおいしいか。組み合わせたときに、前後の皿をおいしくするか

## 道具は温度で割り振る

| 道具 | 温度 | 担当 |
|------|------|------|
| 低温調理器 | 63〜85℃ | 肉、ブロード、タコ、ナス、卵黄、ジェラートのベース |
| 炊飯器 | 保温72℃、調理約90℃ | カレーの長時間保温、野菜の軟化 |
| フライパン、オーブン | 140℃以上 | 焼き色と香ばしさ |
| 冷蔵庫 | 4℃ | 休ませる工程、乾燥、解凍 |
| 冷凍庫 | −18℃ | ストック、氷菓 |

## 欠点を工程に変える

| 現象 | 普通の扱い | このレシピ集での扱い |
|------|------|------|
| 氷の結晶が組織を壊す | 冷凍の欠点 | 生ダコを柔らかくする下処理 |
| 解凍途中で硬い | 待ち時間 | 薄く切るための最適な硬さ |
| 加熱で汁が出る | 身が縮む欠点 | ソースやドレッシングに使う旨味の素 |
| 冷蔵で汁が固まる | 見た目の問題 | 冷凍時に身を守る膜 |
| 密閉では煮詰まらない | 濃度が上がらない欠点 | 香りを逃がさず、濃度は入口の水量で決める |
| 冷蔵中に皮が乾く | 見た目の問題 | 焼いたときにすぐ140℃を超えてパリッとなる |

## 科学の正確さも物語の一部

言い過ぎない。たとえば「グラニータが脂を消す」ではなく「冷たさと酸で感覚を切り替える」と書く。外部のレビューで見つかった誤りは、各レシピの由来や検証ログに修正点として残す。正確な一文のほうが、読んだ人が後で調べたときに信頼に変わる。

## 研究中レシピの進め方

- 研究中のレシピは、温度と時間を暫定値として書き、検証予定を末尾に置く
- 一皿ずつ試して確定させてから、コースのような組み合わせに進む
- 結果は各レシピの検証ログに記録する
