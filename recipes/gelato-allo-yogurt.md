# ジェラート・アッロ・ヨーグルト（研究中）

イタリア旅行で食べて感動したフローズンヨーグルトの再現。日本で食べたことのない、すごくコクのある味だった。
そのお店の作り方は分からない。だからこのレシピは、イタリアのジェラテリアの一般的な作り方から立てた仮説で始まる。チキンカレーと同じく、記憶の味を科学で分解して組み直す。

## 仮説：コクの正体

| | 日本でよくあるフローズンヨーグルト | イタリアのジェラート・アッロ・ヨーグルト |
|------|------|------|
| 発想 | ヨーグルトを凍らせたヘルシーな氷菓 | ジェラートのベースにヨーグルトを混ぜたもの |
| 脂肪 | 低脂肪が多い | 牛乳と生クリームの乳脂肪が入る |
| 空気の量 | 多い（ソフトクリーム状） | 少ない |
| 出す温度 | 低め | −11〜−13℃と高め |

1. **ジェラートのベースが入っている**：牛乳、生クリーム、砂糖を合わせた白いベース（ベース・ビアンカ）にヨーグルトを混ぜる。乳脂肪と乳タンパクが、ヨーグルトだけでは出ないコクと厚みを作る
2. **空気が少ない**：アイスクリームやソフトクリームは空気を多く含ませて軽くする。ジェラートは空気が少なく密度が高いので、ひと口あたりの味が濃い
3. **温度が高い**：舌が冷えすぎず、味と香りを強く感じる

## 材料（約700ml・暫定）

### ベース

- 牛乳 250ml
- 生クリーム 100ml
- スキムミルク 25g
- 砂糖 60g
- 水あめ 20g

### 仕上げ

- 水切りヨーグルト 250g（プレーンヨーグルト約500gを一晩水切りする）
- 塩 ひとつまみ

### 添えるもの

- 季節の果物

## 手順

1. **ヨーグルトを水切りする**：プレーンヨーグルトをキッチンペーパーを敷いたザルに入れ、冷蔵庫で一晩置く
2. **ベースを85℃に**：牛乳、生クリーム、スキムミルク、砂糖、水あめを混ぜて85℃まで加熱する。低温調理器で袋ごと加熱してもよい
3. **急冷して寝かせる**：氷水で急冷し、冷蔵庫で4時間から一晩寝かせる
4. **ヨーグルトを混ぜる**：冷えたベースに水切りヨーグルトと塩を混ぜる。ヨーグルトは加熱しない
5. **アイスクリームメーカーで凍らせる**
6. **冷凍庫で締める**：容器に移して冷凍庫で数時間固める
7. **温度を戻して出す**：出す10〜15分前に冷凍庫から冷蔵庫へ移し、−12℃前後にする
8. **季節の果物を添える**

## 科学解説

### 1. なめらかさは氷の結晶の大きさで決まる

- ヨーグルトは水分が85%以上ある。何もしないと大きな氷の結晶ができてシャリシャリになる
- 結晶を小さく保つ方法は、凍る水を減らす、結晶の間を埋める、凍る温度を下げる、混ぜながら速く凍らせる、の四つ。このレシピは全部使う

### 2. ヨーグルトの水切り

- 凍る水が減るので、結晶が育ちにくい
- タンパク質の割合が増え、結晶の間を埋めてなめらかになる
- 酸味と風味も濃くなる。凍らせると味を感じにくくなるので、濃いくらいでちょうどいい

### 3. スキムミルク

- 乳タンパクと乳糖を、水分を増やさずに足せる
- タンパク質は水を抱えて結晶の成長を邪魔し、コクと厚みを出す

### 4. 糖の種類を混ぜる

- 糖が溶けていると凍る温度が下がる。凍りきらない水が残るので、カチカチにならずすくえる柔らかさになる
- 水あめに含まれる小さい糖は、同じ重さなら砂糖より凍る温度を大きく下げる
- 甘さを増やさずに柔らかさだけを調整できる

### 5. ベースを85℃にする理由

- 殺菌する
- 砂糖とスキムミルクを完全に溶かす
- 乳タンパクの一部がほどけて水を抱えやすくなり、なめらかさが増す
- ナスのパルミジャーナと同じ85℃。低温調理器で袋ごと処理できる

### 6. 寝かせる理由

- 冷蔵中に乳脂肪が細かく固まる。凍らせるときに空気と氷を安定して支えるようになる
- タンパク質が水を抱える時間ができる
- アイスクリーム作りでいうエージングと呼ばれる工程

### 7. ヨーグルトは加熱しない

- フレッシュな酸味と香りを残す
- 生きた乳酸菌も残る。冷凍では多くの乳酸菌が生き残る

### 8. 混ぜながら速く凍らせる

- 静かに凍らせると結晶はゆっくり大きく育つ。混ぜながら速く凍らせると、小さな結晶がたくさんできる
- 冷凍庫で30分おきに混ぜる方法もあるが、なめらかさには限界がある。アイスクリームメーカーを使う理由はここ

### 9. 出す温度

- 一般的なアイスは−18℃前後、ジェラートは−11〜−13℃前後で出す
- 温度が高いほど舌が冷えすぎず、味と香りを強く感じる
- 冷凍庫から出したては硬すぎる。冷蔵庫で10〜15分戻す

## 季節の果物

土台のヨーグルトは主張が控えめなので、どんな果物でも受け止める。土台は科学で固定して、果物は季節で変える。

### 選ぶ基準

1. **香りが立つもの**：冷凍した果物ではなく、生か軽く火を通したものにする。香りは温度が低いと感じにくい
2. **酸と甘さのバランス**：ヨーグルトに酸味があるので、甘い果物は対比が出る。酸っぱい果物ははちみつで和えて調整する
3. **コースで使っていない味**：[コンフィのコース](confit-course.md) ではグレープフルーツとレモンが出ているので、柑橘は避けるか種類を変える

### タンパク質分解酵素に注意

キウイ、パイナップル、いちじく、パパイヤにはタンパク質を分解する酵素がある。ヨーグルトに触れたまま置くと乳タンパクが分解され、苦味が出て水っぽくなる。

- 盛り付けは食べる直前にする
- 軽く火を通すと酵素が働かなくなる。焼いたいちじくやソテーしたパイナップルのように使える

### 季節の例

| 季節 | 果物 | ひと工夫 |
|------|------|------|
| 春 | いちご | 半分に切り、はちみつと和えて果汁を出す |
| 初夏 | さくらんぼ、びわ | そのまま |
| 夏 | 桃、ブルーベリー | 桃は皮をむいてすぐ盛る（変色するため） |
| 秋 | ぶどう、梨、いちじく、柿 | いちじくは直前に盛るか、軽く焼く |
| 冬 | みかん、りんご | りんごはバターで焼いて温かいまま添える |

- 温かい果物を添えると、冷たいジェラートとの温度の対比が強くなる
- 柑橘を使うなら、食べる直前に皮を少し削りかける。皮の油の香りが一番上に乗る

| 最大調理量 | 約600ml |
| 調理時間 | 約40分（最大60分まで調整可） |
| 価格 | 39,600円（税込、2026年10月時点の情報） |

選んだ理由。

- **続けて作れる**：ボウルを凍らせ直す必要がないので、1回作り終えたらすぐ次を作れる。ベースをストックして都度凍らせる運用と、2種類を同時に作る食べ比べに向いている
- **レシピ1回分がほぼ入る**：このレシピの混合液は約625ml。最大調理量を少し超えるので、550ml前後に減らして使う。凍らせる途中で空気を含んで膨らむ点にも注意

| 項目 | 内容 |

| 最大調理量 | 約350ml（出来上がりは約480ml） |
| 調理時間 | 約20〜25分 |

安価だが、このレシピは2回に分ける必要がある。2回目はボウルを凍らせ直すので翌日になる。まとめて作る使い方には向かない。

### 方式の違い

| | 保冷ボウル式 | コンプレッサー式 |
|------|------|------|
| 連続で作る | できない（ボウルの再冷凍に約1日） | できる |
| 結晶の細かさ | 十分 | 冷える力が強く、より細かい |
| 価格 | 安い | 高い |

価格は販売店や時期で変わるので、購入前に確認する。

**家庭用機を店で使う場合の注意**

**営業許可と規格**

店内でデザートとして出すだけの場合と、持ち帰りや包装して販売する場合とでは、必要な許可や守るべき規格が変わる可能性がある。乳製品を使う氷菓には、加熱殺菌の条件や表示の決まりもある。ベースを85℃で処理してからヨーグルトを後から混ぜる工程の扱いも含めて、開業前に管轄の保健所へ確認する。

## 保存

### ストックするのはベース

- 一番おいしいのは作ってから2〜3日。家庭の冷凍庫は扉を開けるたびに表面の温度がわずかに上がる。そのたびに小さな結晶が溶け、残った大きな結晶に水が移って育つ。繰り返すうちにざらつく
- だからストックするのは、85℃で処理して寝かせたベースのほう。小分けにして冷凍しておき、食べたいときに解凍して水切りヨーグルトと混ぜ、凍らせる。凍らせる工程は約40分なので出来たてを食べられる
- コースで出すなら前日か当日朝に凍らせる

### 凍らせたものを保存するなら

1〜2週間で食べきる。結晶の成長を遅らせる工夫は次のとおり。

- 浅く平らな密閉容器に入れる
- 表面にラップを密着させる
- 冷凍庫の奥（扉から遠い場所）に置く
- 食べる分だけ取り出し、容器ごと出し入れしない

水あめとスキムミルクが入っているので、何も入れないものより持ちはいい。

## 検証予定

- 仮説の確認：ヨーグルトだけの版と、ベース入りの版を食べ比べ、コクの差を確かめる
- ベースとヨーグルトの比率を調整する（今は約1:1）
- 水切りの時間でなめらかさと酸味がどう変わるか確かめる
- 出す温度を変えて、味の感じ方を比べる
- 記憶の味にどこまで近づけるか
