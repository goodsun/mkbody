# レシピ集

自炊メニューのレシピ。各レシピには栄養メモと nutrition.csv の対応行を記載する。

## 設計思想：物理で料理

料理を「煮込む」「焼く」といった作業ではなく、温度と時間の設計として扱う。起きる現象そのものは変えられない。でも、どのタイミングで起こすかは選べる。そうすると、欠点とされていた現象が工程に変わる。

レシピをまたいで使っている原理は次のとおり。

| 原理 | 中身 | 使っているレシピ |
|------|------|------|
| コラーゲンは70℃台の長時間でゼラチンになる | 沸騰させずに時間をかけて柔らかくする | チキンカレー、コンボパック、タコのカルパッチョ |
| 野菜の軟化は85℃前後から | 野菜には肉より高い温度を割り当てる | パルミジャーナ |
| メイラード反応は水があると進まない | 先に水を飛ばしてから焼き色をつける | チキンカレー、BBQソース、パルミジャーナ、コンフィ |
| 香りは揮発する、または油に溶ける | 香りは最後に入れる。スパイスは油で開く | チキンカレー、BBQソース、パルミジャーナ、カルボナーラ |
| 密閉すると蒸発しない | 濃度は煮詰めではなく入口の水量で決める | チキンカレー、コンボパック |
| 旨味は掛け算で、しかも頭打ちになる | グルタミン酸とイノシン酸を組み合わせ、足しすぎない | BBQソース、パルミジャーナ、真鯛のカルパッチョ |
| 芽胞は加熱を生き残る | 加熱のあとは必ず急冷し、危険な温度帯を一気に通過させる | 低温調理するすべてのレシピ |
| 冷蔵で寝かせると味が分配される | 急冷のあと冷蔵で休ませる | チキンカレー、コンボパック、タコのカルパッチョ |
| 氷の結晶は組織を壊す | 欠点として避けるか、下処理として使うかを選ぶ | パルミジャーナ、タコのカルパッチョ |

道具は温度で割り振る。75℃の湯煎は肉とブロード、炊飯器は約90℃の軟化、フライパンとオーブンは140℃以上の焼き色、冷蔵庫と冷凍庫は休ませる工程と保存。
