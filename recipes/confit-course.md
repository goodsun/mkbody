# コンフィのイタリアンコース（研究中）

[コンボパック](pulled-combo-pack.md) の鶏ももコンフィをメインに据えたコース。イタリアンの定番構成に沿って、皿ごとに化学のハックを仕込む。
主眼はコース全体でおいしさを最大化すること。各皿を一番うまくできる温度と道具で作る。

## コース設計の原理

| 原理 | 中身 | 設計への反映 |
|------|------|------|
| 感覚の順応 | 同じ味が続くと舌が慣れて感じにくくなる | 皿ごとに主役の味を変える |
| 旨味は頭打ち | 序盤で旨味を最大にすると後半が伸びない | 旨味は低く始めて少しずつ積み上げる |
| 脂は舌を覆う | 脂が残ると次の味がぼやける | 脂の多い皿には酸を添えて舌をリセットする |
| 温度で感じ方が変わる | 温かいと香りが立つ。冷たいと甘味と塩味が弱く感じる | 冷たい皿から始め、温かい皿へ |
| 食感の対比 | 同じ食感が続くと単調になる | なめらか、弾力、とろとろ、パリッと、を順に並べる |
| 満腹感 | メインの時点で空腹が残っていないと一番の皿が負ける | 前菜とプリモは少量 |
| 重複を避ける | 同じ食材や調味料が続くと印象が薄れる | にんにく、トマト、乳製品の重なりを管理する |

## コース構成

| 順 | 構成 | 皿 | 温度 | 味の主役 | 食感 |
|------|------|------|------|------|------|
| 1 | アミューズ | [枝豆の冷製ポタージュ](edamame-potage.md) → プルドポークのクラッカー | 冷→温 | 甘味→甘辛とスモーキー | なめらか→カリッと |
| 2 | アンティパスト・フレッド（冷前菜） | [低温調理タコのカルパッチョ](sous-vide-octopus-carpaccio.md) | 冷 | 酸、苦味 | 弾力 |
| 3 | アンティパスト・カルド（温前菜） | [ナスのパルミジャーナ](eggplant-parmigiana.md)（ひと口のミルフィーユ） | 温 | 旨味、香ばしさ | とろとろとカリッ |
| 4 | プリモ | [低温調理カルボナーラ](sous-vide-carbonara.md)（50〜60g） | 温 | 卵黄のコク | クリーミー |
| 5 | インテルメッツォ（幕間） | レモンのグラニータ（15〜20g） | 冷 | 鋭い酸 | シャリッと |
| 6 | セコンド＋コントルノ | 鶏ももコンフィ、粒マスタードとバルサミコ。カリカリじゃがいも（ひと口分）、紫玉ねぎのピクルス。赤ワインか紅茶を添える | 温 | 焼きの香り、脂 | パリッと |
| 7 | ドルチェ | [ジェラート・アッロ・ヨーグルト](gelato-allo-yogurt.md)、季節の果物 | 冷 | まろやかな酸、果実の香り | なめらか |
| 8 | カッフェ | エスプレッソ | 温 | 苦味 | なし |

甘味から始まり、酸、旨味、コク、鋭い酸、焼きの香り、まろやかな酸、苦味と、皿ごとに主役が変わる。アミューズのプルドポークで旨味は一度跳ね上がるが、これはわざと外したアクセント。直後のカルパッチョで一度リセットしてから、改めて積み上げ直す。香ばしさも旨味と同じく少しずつ積み上げる。パルミジャーナの天面、カルボナーラのベーコンと小さく重ね、皮全面に焼き色がつくコンフィで頂点にする。

## 皿ごとのポイント

### 1. アミューズ：枝豆のポタージュとプルドポークのクラッカー

一皿に二つを乗せて出す。コンボパックの豚を最初のひと口で出し、同じ袋の鶏をメインで出す。同じ袋から生まれた二つの料理が、コースの最初と最後に登場する。

**枝豆の冷製ポタージュ**

- デミタスカップでひと口。甘味となめらかさで舌と胃を起こす
- 乳製品は使わず、オリーブオイルと豆乳で作る。この後のチーズと卵黄に乳脂肪を重ねない
- イタリアのコースではスープもプリモに入る。プリモはカルボナーラが担うので、スープは食前の小さな一杯にする

**プルドポークのクラッカー**

- ほぐしたプルドポークを [BBQソース](bbq-sauce.md) で炒める。ソースの糖分がキャラメル化し、肉の縁がカリッと焦げる。アメリカのBBQでいうバーントエンドに近い香ばしさ
- クラッカーに乗せ、イエローマスタードときゅうりのディルピクルスを添える
- メインの粒マスタードと紫玉ねぎのピクルスとは種類を変える。アミューズはジャンクなアメリカ味、メインは上品なフランス味と役割を分ける
- ソースの水分はすぐクラッカーに移る。乗せるのは出す直前
- 量はひと口だけ。豚はこの後カルボナーラのベーコンでも出てくる

**食べる順番を説明する**

出すときに「スープからどうぞ」とひと言添える。

- BBQの強い甘味と旨味を先に食べると、舌が慣れて枝豆の繊細な甘さを感じにくくなる
- 繊細なものから先に食べれば、両方の味が活きる
- デミタスカップを手前、クラッカーを奥に置くと、説明がなくても自然とスープから手が伸びる
- プルドポークの強さがカルパッチョに残る分は、カルパッチョの酸と苦味でリセットする

### 2. 低温調理タコのカルパッチョ

- サラダを兼ねる。ルッコラを多めに盛り、タコと葉野菜を半々くらいの比率にする。苦味、食感、柑橘の酸、オリーブオイルとサラダの要素はそろっているので、独立したサラダの皿は置かない
- なめらかなポタージュの次に、タコの弾力で食感を切り替える
- タコの旨味はアデニル酸が中心で穏やか。旨味を低く始める出発点に向いている
- にんにくは抜く。パルミジャーナとカルボナーラにも入るため
- トマトではなく柑橘を使う。トマトはパルミジャーナと重なる。柑橘はグレープフルーツにして、苦味でポタージュの甘味と主役を変える
- 冷凍ストックを半解凍で切れる。ドレッシングも5〜10分前にかけられるので、直前の作業が少ない

### 3. ナスのパルミジャーナ（ひと口のミルフィーユ）

- 最初の温かい皿で、旨味を一段上げる
- ひと口サイズにしてチーズの量を抑える。この後のカルボナーラとチーズが続くため
- 冷凍しておいたナスの袋とトマトソースで、当日は重ねて焼くだけ

### 4. 低温調理カルボナーラ

- 量は50〜60g、卵黄1個。メインの前に満腹にしない
- ソースの袋は65℃（長く待たせるなら63℃）の湯煎で待たせておけるので、前菜を出している間に準備が整う
- 茹で汁の塩は控えめにする。ベーコンとチーズで塩分は十分

### 5. レモンのグラニータ

- カルボナーラとコンフィという二つの主役級の皿の間に置く幕間。デザートではなく、スプーン2〜3口の小さな一皿
- 酸味、冷たさ、シャリッとした食感、香りの対比で感覚を切り替える。卵黄とチーズと豚脂のコクから、レモンの明瞭な酸へ。黒胡椒と豚脂の香りから柑橘へ
- 甘くしすぎない。糖が強いと食事の途中でデザートを食べた感覚になり、次のコンフィの塩味が際立ちすぎる
- ローズマリーを入れるならごく微量。多いとコンフィの焼きの香りを覆う。レモンだけでも十分
- 食べ終わってから少し間を置く。冷えすぎた口のままではコンフィの香りを感じにくい
- 段取りの面でも効く。ゲストがグラニータを食べている間に、コンフィの皮を焼ける

### 6. 鶏ももコンフィ

- 皮を下にして重しを乗せて焼く。冷蔵で乾いた皮はすぐに140℃を超え、パリッとなる
- 香ばしさの頂点。パルミジャーナの天面やカルボナーラのベーコンは焼き色が小さな面積にとどまるが、コンフィは皮の全面が焼き色になる。香ばしさを主役にするのはこの皿だけ
- ソースは粒マスタードとバルサミコ。酸と刺激で、コンフィ自身の脂の重さを和らげる
- 赤ワインか無糖の紅茶を添える。渋味のある飲み物は口の中の脂っぽさを減らすことに実験的な根拠がある。グラニータで区切り、ピクルスと渋味で食べている間も脂を抑える
- コントルノのじゃがいもは、重曹をひとつまみ入れたお湯で下茹でしてから袋の脂で焼く。表面がざらざらになりカリカリになる
- じゃがいもはひと口分に抑える。直前のカルボナーラとデンプンが重なり、袋の脂でコンフィとも脂が重なるため。コンフィに脂で焼いたじゃがいもを添えるのはフランスの定番なので、量を減らして残す
- 紫玉ねぎのピクルスで、ひと口ごとに脂を酸で切る

### 7. ジェラート・アッロ・ヨーグルト、季節の果物

- イタリア旅行で食べて感動したフローズンヨーグルトの再現。コースの締めに個人の記憶を置く
- 生クリームだけのジェラートと違い、ヨーグルトの乳酸の酸味があるので重さが残りにくい
- 果物は季節で変える。コースで出ているグレープフルーツとレモンは避ける
- 生か軽く火を通した果物を添える。冷凍した果物より香りが立つ

### 8. エスプレッソ

- 苦味でドルチェの甘さを切り、余韻を締める
- 最後に一番強い香りを置くと、コースの終わりがはっきりする

## 物語

このコースは科学と物語を重視する。

### 一皿にひとつの物理

| 順 | 皿 | 主役の現象 | 鍵になる温度 |
|------|------|------|------|
| 1 | 枝豆のポタージュ、プルドポーク | 緑を守る急冷と、糖のキャラメル化 | 4℃ と 75℃×10時間 |
| 2 | タコのカルパッチョ | 氷の結晶が組織をほどく | −18℃ と 77℃×5時間 |
| 3 | ナスのパルミジャーナ | ペクチンがほどける温度 | 85℃ |
| 4 | カルボナーラ | 卵黄が固まる手前の5℃ | 65℃ |
| 5 | レモンのグラニータ | 粗い氷の結晶 | 凍らせながら削る |
| 6 | 鶏ももコンフィ | 皮の上のメイラード反応 | 75℃×10時間 → 140℃ |
| 7 | ジェラート・アッロ・ヨーグルト | 細かい氷の結晶とタンパク質 | 85℃ → −12℃ |
| 8 | エスプレッソ | 圧力による抽出 | 約90℃ |

### 三つの仕掛け

1. **一つの袋が最初と最後をつなぐ**：アミューズのプルドポークとメインのコンフィは同じ袋から出てくる。最初のひと口で「この袋には、もう一つの料理が入っていました」と伏線を張り、メインで回収する
2. **二つの氷菓が対になる**：同じ「凍る」という現象でも、結晶の大きさと中身で食感がまるで変わる。グラニータは粗い結晶の口直し、ジェラートは細かい結晶とタンパク質のデザート
3. **二幕構成**：第一幕（1〜4皿）は85℃以下でゆっくり起きる変化で旨味とコクを積み上げる。幕間のグラニータで感覚を切り替える。第二幕（6〜8皿）は140℃の焼き色で香ばしさの頂点へ。最後は氷と圧力で締める

### 一皿ごとに選ばれた理由

科学の層に加えて、各皿には選ばれた理由がある。個人的な思い入れで選んだ料理が、味覚設計の中でも合理的な位置に収まっている。

| 皿 | 選ばれた理由 |
|------|------|
| 枝豆のポタージュ、プルドポーク | 導入。プルドポークはメインへの伏線 |
| タコのカルパッチョ | 丁寧な寿司職人の仕事で、タコへの見方そのものが変わった |
| ナスのパルミジャーナ | イタリアで出会った感動 |
| カルボナーラ | イタリアでの残念な体験へのリベンジ。卵黄を精密に管理する低温調理が、その答えになる |
| 鶏ももコンフィ | 自分の調理技術と研究の集大成 |
| ジェラート・アッロ・ヨーグルト | イタリア旅行で忘れられなくなった味 |

タコだけは出発点の種類が違う。他の皿は「おいしさに感動した」体験だが、タコは一つの生き物への見方が変わった体験。「丁寧な仕事で、ありふれた食材の見え方が変わる」は、このレシピ集全体のテーマでもある。

思い入れがあることと、コースで機能することは別。だから各皿は引き続き、科学の基準でも評価する。

### 記憶で締める

ドルチェはイタリア旅行で感動したフローズンヨーグルトの再現。チキンカレーが20年前のネパール料理店の記憶から始まったのと同じく、記憶の味を科学で分解して組み直す。コースの最後に、同じ物語の型がもう一度出てくる。

### 伝える道具

- **メニューカード**：皿の名前の横に鍵になる温度だけを書く。「カルボナーラ　65℃」のように。数字が目に入ると、ゲストは理由を聞きたくなる
- **ひと言の解説**：皿を出すときに一文だけ添える。長い説明はしない
  - カルボナーラ：「卵黄は70℃で固まります。その5℃手前で止めました」
  - コンフィ：「渋味が脂の感覚を和らげるという研究があります」
  - ドルチェ：「イタリアで食べて忘れられなかった味を、仮説から組み立てました」
- **言い過ぎない**：たとえば「グラニータが脂を消す」ではなく「冷たさと酸で感覚を切り替える」と言う。正確な一文のほうが、聞いた人が後で調べたときに信頼に変わる

## 重複の管理

| 要素 | 入る皿 | 対策 |
|------|------|------|
| にんにく | パルミジャーナのソース、カルボナーラ | カルパッチョから抜く |
| トマト | パルミジャーナ | カルパッチョは柑橘にする |
| チーズ | パルミジャーナ、カルボナーラ | パルミジャーナをひと口にする |
| 乳製品 | パルミジャーナ、カルボナーラ、ドルチェ | ポタージュは豆乳。ドルチェはヨーグルトの酸味で重さを残さない |
| マスタード、ピクルス | アミューズ、コンフィ | アミューズはイエローマスタードとディルピクルス、コンフィは粒マスタードと紫玉ねぎで種類を変える |
| 豚 | アミューズ、カルボナーラ | アミューズはひと口だけにする |
| 柑橘 | カルパッチョ、グラニータ | カルパッチョはグレープフルーツ（苦味）、グラニータはレモン（鋭い酸）で役割を変える。ドルチェの果物は柑橘を避ける |
| 氷菓 | グラニータ、ドルチェ | 粗い結晶で甘さ控えめの口直しと、細かい結晶でコクのあるデザート。物性と糖度で体験を分ける |
| 塩 | パルミジャーナ、カルボナーラ、コンフィ | カルボナーラの茹で汁を控えめにする |
| デンプン | カルボナーラ、じゃがいも | じゃがいもをひと口分にする |
| 脂 | カルボナーラ、コンフィ、じゃがいも | グラニータで区切り、ピクルスの酸と飲み物の渋味で和らげる |
| 生野菜 | カルパッチョのみ | ルッコラを多めにしてサラダを兼ねる |

| 19:15 | コンフィ | じゃがいも、ピクルス、粒マスタード、バルサミコを添えて盛る。赤ワインか紅茶を注ぐ | ジェラートを冷蔵庫へ移す。果物を切る |
| 19:35 | ドルチェ | ジェラートを盛り、季節の果物を添える | エスプレッソマシンを予熱 |
| 19:45 | カッフェ | 抽出して出す | なし |

### 段取りの要点

- **カルボナーラはフライパンで和えない**：ベーコンを炒めた直後の鍋肌は100℃を大きく超え、卵が固まる。常温のボウルで和える
- **解凍は逆算する**：タコは半解凍で切りたいので、切る2〜3時間前に冷蔵庫へ。完全に解凍してしまったら、冷凍庫に15〜20分入れて硬さを戻す
- **ナスは乾かしてから焼く**：解凍したナスは水が出る。濡れたままでは100℃に張り付いて焼き色がつかない
- **パルミジャーナは入れっぱなしにしない**：220℃で8〜10分。取り出した後の15分がそのまま休ませる時間になる
- **コンフィは65℃で中まで温める**：冷蔵庫から出したままだと、中を温める前に皮が焦げる。75℃で調理済みなので65℃なら火が入りすぎない。フライパンは皮を焼くだけで済む
- **グラニータが調理時間を作る**：ゲストがグラニータを食べている間にコンフィの皮を焼く。味覚の設計と段取りが同時に良くなる
- **低温調理器1台で2役**：17:00から65℃で、カルボナーラのソースとコンフィを同時に温める
- **オーブンも2役**：220℃でパルミジャーナを焼いたら、80〜100℃に下げて皿とじゃがいもの保温に使う
- **フライパンは2枚**：Aはベーコン、Bはじゃがいもとコンフィ。途中で洗わない
- **茹で汁の塩は0.5%**：通常の半分。ベーコンとチーズで塩分は十分

## 別案：軽めの構成

カルボナーラとパルミジャーナを入れない軽い版。

| 順 | 皿 |
|------|------|
| 1 | グレープフルーツのトニック割り |
| 2 | 苦味葉野菜のサラダ、コンソメのジュレ添え（ブロード袋から） |
| 3 | プルドポークとレモンのパスタ（ブロードで炊くリゾッタータ） |
| 4 | 鶏ももコンフィ、カリカリじゃがいも、紫玉ねぎのピクルス |
| 5 | キャラメリゼしたバナナとヨーグルト |
| 6 | エスプレッソ |

ブロード袋の75℃は沸騰させないので澄んだスープになり、ジュレにすると体温で溶けて旨味が口の中で広がる。パスタは茹でずにブロードで炊くことで、デンプンとゼラチンの二重乳化でソースが安定する。

- 当日の段取りが一人で回るか確かめる
- コース全体の塩分を概算する
