# ラング・ド・シャ（研究中）

薄く焼いたサクサクの焼き菓子。基本は本来の形のプレーン。アレンジとしてパルメザン版とアーモンド版を持つ。
[カルボナーラ](sous-vide-carbonara.md) で余る卵白の使い道になる。卵黄はカルボナーラ、卵白はラング・ド・シャ。一つの食材を二皿に使い切る。

## 基本：プレーンのラング・ド・シャ（約25枚）

バター、砂糖、卵白、粉を同量にするのが本来の配合。

### 材料

| 材料 | 分量 |
|------|------|
| 無塩バター（室温に戻す） | 50g |
| 粉糖 | 50g |
| 卵白（室温に戻す） | 50g |
| 薄力粉 | 50g |
| 塩 | ひとつまみ |

### 手順

1. バターをクリーム状に練り、粉糖と塩を加えてすり混ぜる
2. 卵白を3〜4回に分けて加える。分離しないよう毎回しっかり混ぜる
3. 薄力粉をふるい入れ、ゴムべらで粉気がなくなるまで混ぜる
4. 天板に小さじ1ずつ落とし、スプーンの背で薄く丸く広げる
5. 170℃で10〜12分焼く。縁にこんがり焼き色がついたら焼き上がり
6. 天板の上で冷まし、完全に冷めたら密閉容器に入れる

薄く広げるほどサクサクになる。厚みがばらつくと焼きムラが出る。

## バリエーション

基本からの差分で書く。

| | 基本 | パルメザン版 | アーモンド版 |
|------|------|------|------|
| 粉糖 | 50g | 25g | 30〜40g |
| 追加する粉 | なし | パルメザン30g（細かくすりおろす） | アーモンドプードル30g |
| 塩 | ひとつまみ | なし（チーズの塩気で足りる） | ひとつまみ |
| 仕上げ | なし | 黒こしょう少々 | 好みで黒こしょう |
| 味 | バターと砂糖の素朴な甘さ | 塩気と旨味 | ナッツの甘い香り |
| 食感 | サクッと軽い | サクッと軽い | 脂が多いぶん、ほろっと崩れる |
| 向いている場面 | 紅茶やコーヒーに | ワインのおつまみ、食前のアペリティーヴォ | ジェラートやエスプレッソに添える |

追加する粉は、手順3で薄力粉と合わせてふるい入れる。

### パルメザン版のポイント

- 甘さを控えるために粉糖を半分にしている
- パルメザンは粉チーズよりブロックをすりおろしたほうが香りがずっと強く出る

### アーモンド版のポイント

- アーモンドは脂が多く焦げやすい。縁の色を見て早めに取り出せるようにする
- 黒こしょうはチーズとの組み合わせほど定番ではない。抜くか、大人向けのアクセントとして残すかは試して決める

## 科学解説

### 1. 卵白を室温に戻し、分けて加える

冷たい卵白を入れるとバターが冷えて固まり、乳化が壊れて分離する。3〜4回に分けて加えるのも、一度に入る水分を減らして分離を防ぐため。

### 2. 縁から焼き色がつく

縁は薄いので早く温度が上がる。卵白のタンパク質と砂糖（パルメザン版ではチーズも）でメイラード反応が始まる。焼き上がりの目安が縁の焼き色なのはこのため。

### 3. 天板の上で冷ます

オーブンの中で液体になっていた砂糖が、冷めるとガラスのように固まる。これがサクサク感の正体。熱いうちに動かすと形が崩れる。

### 4. 密閉容器で保存する

砂糖は湿気を吸う。出しておくとすぐ柔らかくなる。

### 5. 砂糖を減らすと何が変わるか

砂糖は焼くときに生地を広げ、カリッとさせる役割も持つ。パルメザン版やアーモンド版のように減らすと広がりにくく、サクサク感が少し弱まる。そのぶんスプーンの背で薄く広げる工程（手順4）が大事になる。

### 6. ブロックのチーズをすりおろす

香りの成分は揮発しやすい。すりおろしたてが一番香る。

## コースでの使い方

[コンフィのコース](confit-course.md) では、アーモンド版をエスプレッソに添える。カルボナーラで余る卵白を使う。2人分で卵白2個、約60〜70gあり、このレシピの50gに足りる。

- パルミジャーナとカルボナーラにチーズが入っているので、パルメザン版だとチーズが三度目になる
- 甘くなめらかなミルクジェラートに添えても、食感の対比になる
- 日持ちのする焼き菓子を手土産にするなら [フィナンシェ](financier.md)

## 注意点

- アーモンド版はナッツを含む。アレルギーのある人に出すときは確認する

## 検証予定

- 基本、パルメザン版、アーモンド版を同じ日に焼き比べる
- アーモンド版の粉糖（30gと40g）と黒こしょうの有無
- 焼き時間と焼き色の関係（アーモンド版は焦げやすい）
- 何日までサクサクが保てるか
