# ラング・ド・シャ（研究中）

薄く焼いたサクサクの焼き菓子。基本はパルメザン入りで、ワインやビールのおつまみにもなる。バリエーションとしてアーモンド版を持つ。
[カルボナーラ](sous-vide-carbonara.md) で余る卵白の使い道になる。卵黄はカルボナーラ、卵白はラング・ド・シャ。一つの食材を二皿に使い切る。

## 基本：パルメザンのラング・ド・シャ（約25枚）

### 材料

| 材料 | 分量 |
|------|------|
| 無塩バター（室温に戻す） | 50g |
| 粉糖 | 25g |
| 卵白（室温に戻す） | 50g |
| 薄力粉 | 50g |
| パルメザンチーズ（細かくすりおろす） | 30g |
| 黒こしょう | 少々 |

### 手順

1. バターをクリーム状に練り、粉糖を加えてすり混ぜる
2. 卵白を3〜4回に分けて加える。分離しないよう毎回しっかり混ぜる
3. 薄力粉とパルメザンを合わせてふるい入れ、ゴムべらで粉気がなくなるまで混ぜる
4. 天板に小さじ1ずつ落とし、スプーンの背で薄く丸く広げる。黒こしょうを振る
5. 170℃で10〜12分焼く。縁にこんがり焼き色がついたら焼き上がり
6. 天板の上で冷まし、完全に冷めたら密閉容器に入れる

### ポイント

- バター、砂糖、卵白、粉を同量にするのがラング・ド・シャの基本。甘さを控えるために粉糖を減らしている
- パルメザンは粉チーズよりブロックをすりおろしたほうが香りがずっと強く出る
- 薄く広げるほどサクサクになる。厚みがばらつくと焼きムラが出る

## バリエーション：アーモンドのラング・ド・シャ

パルメザン30gをアーモンドプードル30gに置き換える。おつまみから焼き菓子に方向が変わる。

| | パルメザン版 | アーモンド版 |
|------|------|------|
| 味 | 塩気と旨味 | ナッツの甘い香り |
| 焼いたときの香り | チーズの香ばしさ | ローストしたナッツの香ばしさ |
| 食感 | サクッと軽い | 脂が多いぶん、ほろっと崩れる |
| 向いている場面 | ワインのおつまみ、食前のアペリティーヴォ | ジェラートやエスプレッソに添える焼き菓子 |

### 置き換えるときの調整

- **粉糖を30〜40gに戻す**：パルメザンの塩気と旨味がなくなるので、25gのままだと味がぼやける可能性がある
- **塩をひとつまみ**：甘さの輪郭がはっきりする。塩キャラメルと同じ理屈
- **黒こしょうは好みで**：チーズとの組み合わせほど定番ではない。抜くか、大人向けのアクセントとして残すかは試して決める
- **焼き色に注意**：アーモンドは脂が多く焦げやすい。縁の色を見て早めに取り出せるようにする

## 科学解説

### 1. 卵白を室温に戻し、分けて加える

冷たい卵白を入れるとバターが冷えて固まり、乳化が壊れて分離する。3〜4回に分けて加えるのも、一度に入る水分を減らして分離を防ぐため。

### 2. 縁から焼き色がつく

縁は薄いので早く温度が上がる。卵白のタンパク質と砂糖（パルメザン版ではチーズも）でメイラード反応が始まる。焼き上がりの目安が縁の焼き色なのはこのため。

### 3. 天板の上で冷ます

オーブンの中で液体になっていた砂糖が、冷めるとガラスのように固まる。これがサクサク感の正体。熱いうちに動かすと形が崩れる。

### 4. 密閉容器で保存する

砂糖は湿気を吸う。出しておくとすぐ柔らかくなる。

### 5. 砂糖を減らすと何が変わるか

砂糖は焼くときに生地を広げ、カリッとさせる役割も持つ。減らすと広がりにくく、サクサク感が少し弱まる。そのぶんスプーンの背で薄く広げる工程（手順4）が大事になる。

### 6. ブロックのチーズをすりおろす

香りの成分は揮発しやすい。すりおろしたてが一番香る。

## コースでの使い方

[コンフィのコース](confit-course.md) では、カルボナーラで余る卵白を使う。2人分で卵白2個、約60〜70gあり、このレシピの50gに足りる。

- **アーモンド版をジェラートに添える**：甘くなめらかなミルクジェラートに、ほろっと崩れるナッツの焼き菓子。食感の対比になる
- **アーモンド版をエスプレッソに添える**：コーヒーと一緒に小さな焼き菓子を出すのはイタリアの定番
- **コースではアーモンド版を使う**：パルミジャーナとカルボナーラにチーズが入っているので、パルメザン版だとチーズが三度目になる

## 注意点

- アーモンド版はナッツを含む。アレルギーのある人に出すときは確認する

## 検証予定

- パルメザン版とアーモンド版の両方を焼き、粉糖の量（25gと35g）で比べる
- アーモンド版の黒こしょうの有無
- 焼き時間と焼き色の関係（アーモンド版は焦げやすい）
- 何日までサクサクが保てるか
