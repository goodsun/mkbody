# プルドポークのペンネ

[プルドポーク](pulled-pork.md) を洋食とイタリアンの合いの子のラグーにしたペンネ。実際に作って美味しかったレシピ。
プルドポークの使い道として、[BBQソース](bbq-sauce.md) や [つけ汁ベース](gyokai-tonkotsu-tsukejiru.md) と並ぶ出口になる。

## 材料（1人前）

| 材料 | 分量 |
|------|------|
| 玉ねぎ | 20g |
| 人参 | 20g |
| にんにく | 2g |
| オリーブオイル | 4g |
| 水 | 60g |
| カゴメ 基本のトマトソース（缶） | 80g |
| デミグラスソース | 20g |
| カゴメ 特選トマトケチャップ | 12g |
| ブルドック 中濃ソース | 12g |
| マキシマム | 少々 |
| プルドポーク | 60g |
| ペンネ（乾） | 50g |

## 手順

1. みじん切りにした玉ねぎ、人参、にんにくを、焦げないようにオリーブオイルで炒める
2. トマトソースとデミグラスソースを入れて少し煮詰める
3. ケチャップと中濃ソースを混ぜて火を入れる
4. 火を止めて水でソースを伸ばし、プルドポークを入れて余熱でほぐす
5. マキシマムで味を整える
6. 茹でたペンネの水気をよく切って加え、火にかけながらさっと炒める
7. 程よい水分に煮詰まったらお皿に盛り付ける

## 科学解説

### 1. ソフリットで甘みの土台を作る

玉ねぎ、人参、にんにくを焦がさずに炒めるのは、イタリアのソフリットそのもの。焼き色をつけないので、香ばしさではなく野菜の甘みだけが出る。

### 2. 旨味の層が厚い

| 素材 | 主な旨味 |
|------|------|
| トマトソース、ケチャップ | グルタミン酸 |
| デミグラスソース | 牛の出汁とゼラチン、焼きの香り |
| 中濃ソース | 野菜と果物の甘み、スパイス、酢 |
| マキシマム | 塩とうま味調味料、スパイス |
| プルドポーク | イノシン酸とゼラチン |

グルタミン酸とイノシン酸の相乗効果が何重にも起きている。

### 3. ケチャップに火を入れる（手順3）

ナポリタンの「ケチャップを焼く」と同じ技。加熱で酢のツンとした酸味が飛び、糖が少しキャラメル化して、角の取れた甘さになる。

### 4. プルドポークは火を止めてから（手順4）

プルドポークはもう火が通っている。余熱で温めると肉汁が抜けず、ゼラチンが溶けて繊維がほどける。強火で煮込むと肉が締まってパサつく。

### 5. 水気を切ってからソースと炒める（手順6）

ペンネの表面のデンプンと、プルドポークのゼラチンがソースの中で合わさり、つやのある絡むソースになる。[カルボナーラ](sous-vide-carbonara.md) やリゾッタータと同じ乳化の理屈。ペンネの筒の中にもソースが入り込む。

## 栄養メモ（1人前）

約460kcal / たんぱく質19.3g / 脂質18.6g / 炭水化物56.8g / 食塩相当量2.9g

- トマトソースはカゴメ 基本のトマトソースの表示値（100gあたり55kcal、たんぱく質1.4g、脂質1.9g、炭水化物8.0g、食塩相当量0.6g）で計算
- プルドポークは nutrition.csv のプルドポーク（ソース抜き）の値を60gに換算
- その他は日本食品標準成分表（八訂）ベースの推定値
- 塩分の内訳：プルドポーク約0.8g、中濃ソース約0.7g、トマトソース約0.5g、ケチャップ約0.4g、マキシマム約0.3g、デミグラスソース約0.3g
- **茹で汁の塩分は含まない**。塩を入れた湯で茹でると、その分が上乗せされる。マキシマムとソース類で塩分は十分にあるので、茹で汁の塩は控えめでよい
